# Smart Attendance + Productivity Monitor (Full Stack)

## 1) Backend (Spring Boot + MySQL + JWT)
- Path: `smart-monitor-backend`
- Configure DB password in `src/main/resources/application.properties`
- Run:
```bash
cd smart-monitor-backend
mvn spring-boot:run
```

## 2) Frontend (React + Tailwind)
- Path: `smart-monitor-frontend`
- Setup:
```bash
cd smart-monitor-frontend
cp .env.example .env
npm install
npm run dev
```
